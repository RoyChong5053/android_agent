# Skill: 拉莫遗址刷经验 (lamo_ruins)

> 实战：2026-09-19。次元地下城「拉莫遗址(哈勒普)5阶段」刷经验。
> 痛点：每局结束都要手动点「再来一次」，极烦。
> 代码：`core/skills/lamo_ruins.py`（纯模板匹配 + 定时点击的傻瓜循环）。
> 模板：`data/templates/lamo/`。战绩：实跑 2 局全自动，每局约 157s。

## 1. 前置与定位

- **玩家先手动打完第一轮**，处理掉一次性 popup（领袖技能 / 探索战斗等），再启动脚本。
- 脚本从**胜利结算**开始接管，只负责「胜利后的结算段」。
- 游戏内置「连续战斗」会自动续下一局；脚本兜底自动续战停掉后的重进（战斗开始 / 开始战斗）。

## 2. 单局流程

```
队伍选择 --开始战斗--> [弹窗:是/是] --加载~12s--> 自动战斗(x3,~150s) --胜利-->
奖励结算(无按钮) --点(720,500)开箱--> --点(720,370)--> [确认(掉落)] --> 再来一次 --> 下一局
```

## 3. 识别与点击（`CHECKS` 按优先级）

弹窗 overlay 必须排在底层画面之前（`开始战斗` 会隔着弹窗命中）。

| 优先级 | 模板 | 含义 | 动作 |
|---|---|---|---|
| 1 | `popup_yes` | 是（领袖技能/探索战斗弹窗） | 点匹配中心 |
| 2 | `confirm` | 确认（掉落奖励弹窗） | 点匹配中心 |
| 3 | `again` | 再来一次 | 点匹配中心，计一局 |
| 4 | `battle_start` | 战斗开始（遗址详情弹窗） | 点匹配中心 |
| 5 | `start_battle` | 开始战斗（队伍选择） | 点匹配中心 |
| 6 | `reward_title` | 奖励（胜利结算，无按钮） | 点 (720,500)→(720,370) 推进 |

- 阈值统一 0.85。战斗画面所有模板最高 ~0.55，不会误触。
- 无匹配时视为「战斗中/未知」，sleep 后重试。

## 4. 运行

```bash
python3 -m core.skills.lamo_ruins --rounds 0     # 无限刷
python3 -m core.skills.lamo_ruins --rounds 20    # 刷 20 局
python3 -m core.skills.lamo_ruins --dry-run      # 只识别不点击（调试）
```

## 6. 踩过的坑

1. **模板隔着弹窗命中**：`start_battle` 在弹窗帧仍 1.00（队伍选择在弹窗后可见）。修：`popup_yes` 排第一。
2. **两个弹窗「是」几乎一样**：一个模板即可，按匹配位置点，别写死坐标。
3. **结算「确认」连中两次**：两个掉落弹窗，位置差 ~45px，照点。
4. **结算画面无按钮**：必须点屏幕推进（先开箱再下一步），不能只等。
5. **游戏自动续战**：别假设每局都要点开始；脚本只做「有按钮就点」。
