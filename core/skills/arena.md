## 1. 竞技场 vs 地下城：逻辑差异

| | 巨人B9 | 竞技场 |
|---|---|---|
| 批量机制 | 「连续战斗」×10 | 无，每局手动 |
| 战斗操作 | 游戏全自动 | 每局手动开 **×3 + 自动**（▶变⏸） |
| 对手 | 固定B9 | 名单挑最弱（等级/复仇CD一直变，可下滑翻页） |
| 体力 | 能量 | 翅膀（左下 x/10，约30分钟回1） |
| 失败 | 重试即可 | 切后台=判负(-11分)+扣翅膀；闪退=本局翅膀大概率白给 |

## 2. 单局流程（每步转移都要验证，不盲sleep）

```
名单(arena_list) --VL选最弱--> 点[战斗] --等队伍选择(开始战斗按钮模板)-->
队伍选择(固定4×40直接开) --点开始--> 等战斗UI(底部按钮可读,90s) -->
开x3+自动(图标投票+行为验证) --> 等胜利(40s无推进则自愈重开自动) -->
点确认 --> 回名单
```

坐标（1440x720，**实测有效值，勿凭肉眼改**）：
- `SPEED_TAP=(222,668)` 速度档；`AUTO_TAP=(285,668)` 自动开关
  （注意：与截图目测中心偏~50px，以实测为准，见坑#5）
- `START=(1180,460)` 开始战斗；`CONFIRM=(720,360)` 胜利确认（胜利页点任意处都可确认）
- 名单「战斗」按钮：x=1090固定列，y用 `arena_fight_btn.png` 多目标匹配（≥0.9，行间距>40去重）

## 3. 感知：模板 + VL 分工

- 模板（毫秒级，主循环）：`arena_title`→`arena_list`（`detect_state`第12状态）；
  `battle_speed_x1/x3`、`battle_auto_on/off`、`arena_pause`、`arena_fight_btn`、`arena_startbtn`。
  胜利页与地下城**共用** `victory_title`（竞技场胜利0.984）。
- VL（只做读数，不做定位）：`vl_sweep.parse_list()` 一次读翅膀+全行名单
  `{wings, opponents:[{row,level,name,available}]}`。
- VL行列对应校验：VL可打行数 == 模板按钮数，不等则转人工（防点错行）。

## 4. 本地模型对照（llama.cpp :12888，RTX4060 8G）

| 模型 | 速度 | 名单解析 | 备注 |
|---|---|---|---|
| Qwen3.6-35B | ~25-40s/次 | 准（含等级/名字/可打性全对） | 约1/3空回，需3重试 |
| Qwen3.5-4B | ~16-17s/次 | 干净截图准；**半截行截图易空回/截断** | list类prompt需 `max_tokens=1536`（1024会被截断JSON） |

- server**单slot串行**：3并发==串行（77s）。并行靠「后台跑」不靠「并发调」。
- 通用describe prompt（按钮+坐标）两种模型都经常空回 → 只用专用小prompt（读数/分类/选行）。
- grounding偏差~60px：VL只选行，精确定位一律模板匹配。

## 5. 踩过的坑

1. **小图标交叉误报**：×1/×3、▶/⏸长得太像，x1模板在x3图标上0.98、⏸模板在▶上0.92。
   修：相对比较（`>0.96 and 自>互`）+ **行为验证** `_progressing()`（15s内帧差>12两次才算真开）。
2. **手动stall卡死**：自动没开时战斗停技能选择，干等5分钟超时（R3）。
   修：等待循环加「无推进」检测（40s帧差<5 → 自愈点自动）。**任何等待都要有无推进检测，不只看超时。**
3. **盲sleep误转移**：点对手3s后直接点开始，队伍选择没出→点空→加载误判→整局fail（R4）。
   修：`_wait_startbtn`（开始战斗按钮模板+名单补点）+ `_wait_battle_ui`（底部按钮可读才进ensure）。
4. **切后台=判负**：校准乱点切出游戏，-11分+扣翅膀。修：只点游戏内大按钮；暂停菜单用BACK关。
5. **肉眼坐标偏~50px**：SPEED目测170实测222，AUTO目测222实测285。修：小按钮坐标一律条带放大+模板定位；
   根本修（P4）：scrcpy control socket替代`adb input tap`。
6. **战斗动画吞输入**：点后无变化要重试；重要转移用`detect_state`复核（沿用地下城经验）。
7. **事件弹窗X点不掉**：登录堆叠弹窗加载完成前无响应。修：BACK键连按清栈。
8. **nohup丢PYTHONPATH**：脚本文件运行时cwd不进sys.path（`python -c`才进）。修：`PYTHONPATH=. nohup`。
9. **重启后模板漂移**：reboot后`arena_title` 1.0→0.70（差几个像素+整体变亮）。
   修：模板只裁文字核心（避开边缘/装饰菱形），重建后新老截图全1.0、胜利0.535正确拒绝。
   教训：模板取「最小可辨别特征」；重启/更新后跑一遍回归（11+1用例）。
10. **闪退恢复**：游戏闪退一次；重进后未确认的胜利页会重现（服务端已记胜），翅膀-1。
    修：任何异常回归第一步先截图+`detect_state`，别假设位置。
